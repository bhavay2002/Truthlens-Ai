## 🔧 Correct Load Implementation (Fail-Fast)

```python
def load_checkpoint(path, model, optimizer=None, scheduler=None, scaler=None):
    checkpoint = torch.load(path, map_location="cpu")

    # HARD VALIDATION
    required_keys = ["model_state_dict", "step", "epoch"]
    for k in required_keys:
        if k not in checkpoint:
            raise RuntimeError(f"Checkpoint missing required key: {k}")

    model.load_state_dict(checkpoint["model_state_dict"], strict=True)

    if optimizer and checkpoint.get("optimizer_state_dict"):
        optimizer.load_state_dict(checkpoint["optimizer_state_dict"])

    if scheduler and checkpoint.get("scheduler_state_dict"):
        scheduler.load_state_dict(checkpoint["scheduler_state_dict"])

    if scaler and checkpoint.get("scaler_state_dict"):
        scaler.load_state_dict(checkpoint["scaler_state_dict"])

    return checkpoint
```

## ⚠️ Critical Rule

> **Never load with blind assumptions. Validate schema before use.**

# ✅ Fix: Implement Safe Checkpoint Retention

## Step 1: Use Unique, Traceable Names

```python
checkpoint_path = f"{dir}/checkpoint-step-{step}.pt"
```

---

## Step 2: Safe Cleanup Logic

```python
def cleanup_checkpoints(checkpoint_dir, keep_last=5, keep_best=True):
    checkpoints = sorted(
        checkpoint_dir.glob("checkpoint-step-*"),
        key=lambda x: int(x.name.split("-")[-1])
    )

    if len(checkpoints) <= keep_last:
        return

    to_delete = checkpoints[:-keep_last]

    for ckpt in to_delete:
        ckpt.unlink()
```
