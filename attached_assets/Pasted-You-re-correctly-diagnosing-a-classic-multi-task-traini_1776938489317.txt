# 🔧 STEP-BY-STEP FIX PLAN (Production-Level)

## **STEP 1 — Enforce Strict Label Masking (FOUNDATIONAL)**

This is non-negotiable. Without it, everything else is meaningless.

### ✅ Goal

Only compute loss where labels are valid (not NA).

### 🔧 Implementation (PyTorch)

Assume:

* `targets = -1` represents NA
* Multi-label classification (BCE)

```python
def masked_bce_loss(logits, targets):
    mask = (targets != -1).float()  # 1 = valid, 0 = ignore

    loss = torch.nn.functional.binary_cross_entropy_with_logits(
        logits, targets.float(), reduction="none"
    )

    loss = loss * mask

    # Avoid divide-by-zero
    denom = mask.sum().clamp(min=1.0)

    return loss.sum() / denom
```

### ⚠️ Critical Checks

* NEVER average over full batch → always normalize by valid labels only
* Log `mask.sum()` per batch → if near 0 → your batch is useless

## OPTION B — Inverse Frequency Weighting

Compute once from dataset:

```python
task_weights[task] = 1 / (num_valid_samples + 1e-6)
```

Normalize:

```python
total = sum(task_weights.values())
task_weights = {k: v / total for k, v in task_weights.items()}
```

## OPTION C — GradNorm (PRODUCTION-GRADE)

Core idea:
Balance gradients, not just loss values.

High-level:

```python
# pseudo
g_i = grad_norm(task_i_loss)
target_g = mean(g_i)

loss_weight_i *= (g_i / target_g) ** alpha
```

Use `alpha ≈ 0.5`

👉 This prevents one task from dominating training dynamics.

---

## OPTION D — Uncertainty Weighting (Kendall et al.)

Add learnable parameters:

```python
self.log_sigma = nn.Parameter(torch.zeros(num_tasks))
```

Loss:

```python
weighted_loss = 0

for i, task in enumerate(tasks):
    precision = torch.exp(-self.log_sigma[i])
    weighted_loss += precision * task_loss + self.log_sigma[i]
```
