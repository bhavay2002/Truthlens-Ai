## 🔧 FIX 1 — Rate Limiting (Core Solution)

```python
class AnomalyLogger:
    def __init__(self, max_logs=50, log_every=20):
        self.count = 0
        self.max_logs = max_logs
        self.log_every = log_every

    def should_log(self, step):
        if self.count >= self.max_logs:
            return False
        return step % self.log_every == 0
```

Usage:

```python
if is_spike and logger.should_log(step):
    save_anomaly()
    logger.count += 1
```

# ✅ 12. Gradient Norm Always ≈ 1.0 (Critical Observability Bug)

## 🎯 Diagnosis

This almost always means:

```python
torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
```

👉 You are **only seeing post-clipped norms**

---

## ⚠️ Why This Is Dangerous

You lose visibility into:

* exploding gradients
* task dominance
* instability cycles

Your system becomes **blind but “looks stable”**

---

## 🔧 FIX 1 — Log BOTH Pre and Post Clip Norms

```python
def get_grad_norm(parameters):
    total = 0
    for p in parameters:
        if p.grad is not None:
            total += p.grad.data.norm(2).item() ** 2
    return total ** 0.5
```

Usage:

```python
pre_clip = get_grad_norm(model.parameters())

torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)

post_clip = get_grad_norm(model.parameters())

logger.info({
    "grad_norm_pre": pre_clip,
    "grad_norm_post": post_clip
})
```
