## 🔧 STRATEGY A — Masked Loss + True Normalization

```python
def compute_multitask_loss(outputs, batch, tasks):
    total_loss = 0.0
    active_tasks = 0

    for task in tasks:
        logits = outputs[task]
        labels = batch[task]

        mask = (labels != -1)

        if mask.sum() == 0:
            continue  # skip — no fake loss

        loss = F.binary_cross_entropy_with_logits(
            logits[mask], labels[mask].float()
        )

        total_loss += loss
        active_tasks += 1

    if active_tasks == 0:
        return None  # skip batch entirely

    return total_loss / active_tasks
```

## ⚠️ Key Insight

You **do NOT need every task in every batch**
👉 You need **balanced gradient exposure over time**
