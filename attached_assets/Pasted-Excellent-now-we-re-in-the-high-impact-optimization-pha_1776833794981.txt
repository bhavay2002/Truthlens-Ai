# 🔥 1. Tokenization Bottleneck (CRITICAL)

## ❌ Your current problem

You tokenize inside `collate_fn`:

```python
enc = tok(texts, ...)
```

👉 This runs **every batch, every epoch** → massive CPU bottleneck

---

## ✅ FIX — Pre-tokenize dataset (BIGGEST WIN)

### Move tokenization into Dataset

```python
class TruthLensMultiTaskDataset(Dataset):
    def __init__(self, df, tokenizer, max_length):
        self.encodings = tokenizer(
            df["text"].tolist(),
            padding=False,              # 🔥 important
            truncation=True,
            max_length=max_length,
        )
        self.labels = ...

    def __getitem__(self, idx):
        item = {k: torch.tensor(v[idx]) for k, v in self.encodings.items()}
        item["labels"] = ...
        return item
```

---

### Update DataLoader

```python
collate_fn = DataCollatorWithPadding(tokenizer)
```

## 🚀 Impact

| Before             | After           |
| ------------------ | --------------- |
| Tokenize per batch | Tokenize once   |
| CPU bottleneck     | Removed         |
