## ✅ FIX: **Two-Level Loss Normalization (Critical)**

### Level 1 — **Per-task normalization by label density**

```python id="lvl1norm"
def normalize_by_density(loss, labels):
    valid = (labels != -100).sum().clamp(min=1)
    return loss / valid
```

---

### Level 2 — **Running-scale normalization (stabilizes magnitude drift)**

```python id="lvl2norm"
class TaskNormalizer:
    def __init__(self, momentum=0.9):
        self.momentum = momentum
        self.running = {}

    def update(self, task, loss):
        val = loss.detach()
        if task not in self.running:
            self.running[task] = val
        else:
            self.running[task] = (
                self.momentum * self.running[task]
                + (1 - self.momentum) * val
            )
        return loss / (self.running[task] + 1e-6)
```

### 🔧 Do this:

```python id="task_forward"
def forward_task(model, batch, task):
    mask = batch[f"{task}_label"] != -100

    if mask.sum() == 0:
        return None

    inputs = {k: v[mask] for k, v in batch.items() if k in ["input_ids", "attention_mask"]}
    labels = batch[f"{task}_label"][mask]

    logits = model(**inputs)[task]

    return logits, labels
```
