# 3. Add Experimental Setup Section (VERY IMPORTANT)

This is the single biggest realism improvement.

Add this after System Overview.

---

# NEW SECTION

```markdown
## Experimental Configuration

The models were trained and evaluated using a research-oriented experimental setup focused on reproducibility and limited-resource execution.

| Parameter | Value |
|---|---|
| Framework | PyTorch 2.x + HuggingFace Transformers |
| Base Model | RoBERTa-base |
| Optimizer | AdamW |
| Learning Rate | 2e-5 |
| Batch Size | 16 |
| Epochs | 4 |
| Max Sequence Length | 512 |
| Loss Functions | CrossEntropyLoss, BCEWithLogitsLoss |
| Validation Split | 10% |
| Random Seed | 42 |
| Runtime Environment | Google Colab + Local CPU Testing |
| GPU Used During Training | NVIDIA Tesla T4 |
| Inference Environment | CPU-only |
```

# 5. Add Realistic Research Constraints

Human-written reports mention limitations naturally.

Add this section.

---

# NEW SECTION

```markdown
## Development Constraints

The project was developed under limited academic resources and time constraints. Due to hardware limitations, some experiments were performed on reduced dataset sizes and cloud notebook environments.

Certain advanced modules such as sarcasm detection and multilingual analysis were implemented only at a prototype level and require further improvement for real-world deployment.

External API dependency also limited large-scale concurrent testing.
```
