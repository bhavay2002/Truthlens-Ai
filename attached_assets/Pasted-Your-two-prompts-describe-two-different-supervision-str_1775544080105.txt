# Step 1 — Convert Entity Columns to Binary

Entity columns should be converted to binary values:

```
hero_entity = 1 if hero_entities is not empty else 0
villain_entity = 1 if villain_entities is not empty else 0
victim_entity = 1 if victim_entities is not empty else 0
```

Implement this using a helper function:

```python
def _entity_to_binary(self, entity_field):
    if entity_field is None:
        return 0
    if isinstance(entity_field, str) and entity_field.strip() == "":
        return 0
    return 1
```


Full implementation:

```python
hero_entity = self._entity_to_binary(row.get("hero_entities"))

hero = max(hero_original, hero_entity)
villain = max(villain_original, villain_entity)
```

| Case                   | Result       |
| ---------------------- | ------------ |
| binary=1 entity empty  | keep 1       |
| binary=0 entity exists | convert to 1 |
| both exist             | keep 1       |
