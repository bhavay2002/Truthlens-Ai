## ✅ 4.1 Gradient-Normalized Loss (GradNorm) — MUST IMPLEMENT

This directly **balances gradient magnitudes per task**, not just loss values.

### 🔧 Implementation

```python
class GradNormBalancer:
    def __init__(self, model, task_names, alpha=0.5):
        self.task_names = task_names
        self.alpha = alpha
        self.initial_losses = None

    def compute_grad_norm(self, loss, shared_params):
        grads = torch.autograd.grad(loss, shared_params, retain_graph=True, create_graph=True)
        return torch.norm(torch.stack([g.norm() for g in grads if g is not None]))

    def balance(self, losses, shared_params):
        if self.initial_losses is None:
            self.initial_losses = [l.detach() for l in losses]

        grad_norms = []
        for loss in losses:
            grad_norms.append(self.compute_grad_norm(loss, shared_params))

        avg_grad = torch.mean(torch.stack(grad_norms))

        loss_ratios = [l / init for l, init in zip(losses, self.initial_losses)]
        target_grads = [avg_grad * (r ** self.alpha) for r in loss_ratios]

        grad_loss = sum(torch.abs(g - t) for g, t in zip(grad_norms, target_grads))

        return grad_loss
```

## ✅ 4.2 Task Loss Scaling via Learnable Weights (Uncertainty Weighting)

You need **adaptive weighting**, not static.

```python
class MultiTaskLoss(nn.Module):
    def __init__(self, num_tasks):
        super().__init__()
        self.log_vars = nn.Parameter(torch.zeros(num_tasks))

    def forward(self, losses):
        total = 0
        for i, loss in enumerate(losses):
            precision = torch.exp(-self.log_vars[i])
            total += precision * loss + self.log_vars[i]
        return total
```
