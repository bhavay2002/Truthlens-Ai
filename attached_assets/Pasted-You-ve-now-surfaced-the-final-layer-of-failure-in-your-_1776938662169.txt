### 🔧 Implementation (Drop-in Module)

```python id="uncertainty_weighting"
class MultiTaskLoss(nn.Module):
    def __init__(self, tasks):
        super().__init__()
        self.tasks = tasks
        self.log_vars = nn.Parameter(torch.zeros(len(tasks)))

    def forward(self, task_losses):
        total_loss = 0

        for i, loss in enumerate(task_losses):
            if loss is None:
                continue

            precision = torch.exp(-self.log_vars[i])
            weighted = precision * loss + self.log_vars[i]

            total_loss += weighted

        return total_loss
```

---

### ⚠️ Important Notes

* `log_vars` automatically:

  * ↓ weight for noisy/high-loss tasks
  * ↑ weight for stable tasks
* This prevents ideology from dominating
