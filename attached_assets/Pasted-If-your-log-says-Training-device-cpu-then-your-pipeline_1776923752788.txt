# 🚨 Root Cause Categories

## 1. CUDA not detected at runtime

The most common failure:

```python
torch.cuda.is_available()  # → False
```

### Why this happens:

* PyTorch installed without CUDA support
* CUDA drivers missing / incompatible
* Running inside environment without GPU access (Docker, Colab CPU, etc.)

---

## 2. Device selection logic is wrong

Typical bug:

```python
device = torch.device("cpu")  # hardcoded ❌
```

or

```python
device = torch.device("cuda" if False else "cpu")  # logic bug ❌
```

---

## 3. Model not moved to GPU

Even if CUDA is available:

```python
model.to(device)
```

If this line is missing → everything stays on CPU.

---

## 4. Data not moved to GPU

Classic silent issue:

```python
inputs = inputs.to(device)
labels = labels.to(device)
```

If omitted → CPU execution continues.

---

## 5. Running in CPU-only environment

From your logs:

👉 You're running on a **CPU machine (likely local / wrong runtime / misconfigured container)**
